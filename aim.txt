1. PROJECT OVERVIEW & VISION
--------------------------------------------------------------------------------
AETHER is a modern, high-performance, API-powered e-commerce storefront for
precision-engineered personal computing and acoustic hardware (flagship 
smartphones, studio planar magnetic headphones, minimalist smart wearables, 
and wireless soundboxes).

The platform is designed to be enterprise production-grade, secure, and resilient:
- Fast, rich user interface with responsive micro-animations and zero-layout shifts.
- Dual authentication: One-click Google Cloud Console OAuth 2.0 AND traditional
  Email & Password credentials signup/login.
- Robust database persistence via Supabase / PostgreSQL with comprehensive audit 
  logging (activity_logs, order_timeline, email_logs, inventory_ledger).
- Automated transactional email receipts and courier dispatch notifications via 
  Mailgun REST API.
- Customer Self-Service Portal (/account) for profiles, addresses, security, and reviews.
- Executive Admin & Staff Control Terminal (/admin) for live revenue metrics, 
  order fulfillment, catalog stock adjustments with inventory ledger, and coupon campaigns.
- Native resilience: works seamlessly with local storage/memory fallback in 
  development before API keys are connected, and automatically syncs to live 
  cloud databases once keys are configured.


2. TECHNOLOGY STACK
--------------------------------------------------------------------------------
- Core Framework:      Next.js 15 (App Router, Server & Client Components)
- UI Library:          React 19
- Styling:             Modern Vanilla CSS Design System (Custom HSL color tokens,
                       glassmorphism, dark obsidian aesthetic, responsive layouts)
- Icons:               Lucide React
- Database:            Supabase / PostgreSQL (Postgres 15+)
- Client Database SDK: @supabase/supabase-js, @supabase/ssr
- Email Service:       Mailgun Transactional API (HTML receipts & shipping notifications)
- Authentication:      Supabase Auth + Google Cloud Console OAuth 2.0 + Email/Password
- Visual Polish:       Canvas Confetti (order placement celebrations)

6. INSTRUCTIONS FOR ANY DEVELOPER OR AI AGENT READING THIS
--------------------------------------------------------------------------------
1. To start the app locally:
   run: `npm run dev` (running at http://localhost:3000)

2. To build and validate types across all 33 routes:
   run: `npm run build`

3. The app is completely non-breaking:
   Even if the user has not added their Supabase, Google, or Mailgun keys, the 
   store functions smoothly with mock/local fallbacks. Once `.env.local` keys 
   are added, it automatically switches to live cloud mode.

4. To set up Supabase:
   Copy [`supabase/schema.sql`] into Supabase SQL Editor and execute.
